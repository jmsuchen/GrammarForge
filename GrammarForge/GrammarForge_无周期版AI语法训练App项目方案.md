# GrammarForge：无周期版 AI 语法训练 App 项目方案

## 一、项目概述

GrammarForge 是一款基于 DeepSeek API 的英语语法输出训练 iOS App，面向中国英语学习者，重点解决“知道语法规则，但无法在写作和口语中稳定使用”的问题。

本项目不采用固定周期课程，不以“30 天完成”“每日打卡”为核心，而是采用按能力解锁的训练机制。用户只有在某个语法点达到稳定正确的标准后，系统才会推荐进入下一阶段。

核心训练闭环如下：

```text
学习语法点
→ 中译英输出
→ AI 批改
→ 错误归类
→ 相似题复练
→ 掌握度提升
→ 解锁下一语法点
```

项目目标不是让用户“看完语法知识”，而是帮助用户真正做到：

```text
我能在写作和口语里稳定用出这个语法。
```

## 二、项目核心定位

### 2.1 产品定位

GrammarForge 是一个基于能力树的英语语法自适应输出训练系统。

它不是普通 AI 聊天 App，也不是传统语法课 App，而是把语法学习转化为持续输出、即时反馈和针对性复练的训练工具。

### 2.2 目标用户

主要用户包括：

1. 有一定英语基础，但语法输出不稳定的学习者
2. 准备四六级、考研、雅思、托福等考试的学生
3. 写作时经常出现时态、从句、介词和句子结构错误的学习者
4. 想提升英语口语和写作表达准确性的长期学习者

### 2.3 核心价值

GrammarForge 解决的核心问题是：

1. 学生知道语法规则，但不会主动使用
2. 做选择题正确，写句子却容易出错
3. 错误反复出现，但缺少系统归类
4. 学习节奏容易被固定周期打断
5. 缺少针对同类错误的高频复练

因此，本项目采用“能力驱动”而非“时间驱动”的学习模式。

## 三、训练模式：无固定周期，按能力解锁

### 3.1 设计原则

App 不显示“第几天课程”，也不要求用户按固定日期完成任务。

用户每次打开 App 时，看到的是：

```text
当前能力等级
当前推荐训练
近期薄弱点
下一步建议
```

这样即使用户中断几天，学习路径也不会失效。系统会根据用户真实表现继续推荐最适合的训练内容。

### 3.2 语法点掌握度

每个语法点都有独立掌握度，例如：

```text
主谓宾结构：91%
现在完成时：82%
定语从句：64%
非谓语 doing：55%
介词搭配：48%
```

掌握度用于判断用户是否可以进入下一阶段。

### 3.3 推荐解锁标准

一个语法点建议满足以下条件后，进入“基本掌握”或“可解锁下一语法点”的状态：

1. 连续完成 3 组训练
2. 平均正确率不低于 80%
3. 同类错误重复率不高于 20%
4. 能完成 2 句自由造句

达标后系统提示：

```text
你已经基本掌握“现在完成时”，建议进入“现在完成进行时”训练。
```

未达标时，系统继续生成相似题复练，而不是机械进入下一课。

## 四、核心功能模块

## 4.1 语法能力树

GrammarForge 不采用日历式课程，而是采用“能力树”结构。

一级模块包括：

1. 句子骨架
2. 时态系统
3. 从句系统
4. 非谓语
5. 被动语态
6. 比较结构
7. 介词搭配
8. 雅思写作句型
9. 口语表达句型

示例结构：

```text
句子骨架
├── 主谓
├── 主谓宾
├── 主系表
├── there be
├── 主谓双宾
├── 主谓宾补
└── 简单句合并

从句系统
├── 宾语从句
├── 定语从句
├── 主语从句
├── 表语从句
├── 原因状语从句
├── 条件状语从句
├── 让步状语从句
└── 从句合并训练
```

每个语法点有以下状态：

1. 未解锁
2. 可训练
3. 训练中
4. 基本掌握
5. 熟练掌握
6. 需要复习

## 4.2 自适应训练推荐

用户进入首页后，系统推荐当前最需要训练的语法点。

示例：

```text
当前推荐训练：
1. 现在完成时
2. 定语从句
3. 介词搭配

推荐原因：
你最近在这三个语法点上的错误率较高。
```

MVP 阶段可以先按错误次数排序：

```text
优先级 = 错误次数 + 最近错误权重 + 技能重要程度
```

后续版本可以升级为：

```text
训练优先级 = 错误率 × 0.5 + 最近错误权重 × 0.3 + 重要程度 × 0.2
```

## 4.3 中译英训练

中译英是 App 的核心训练方式，因为它可以直接检验用户是否能够主动输出语法结构。

训练页面示例：

```text
语法点：现在完成时

中文句子：
我已经学习英语三个月了。

请输入英文：
[ 输入框 ]

[ 提交批改 ]
```

DeepSeek API 返回示例：

```json
{
  "is_correct": false,
  "score": 72,
  "corrected_sentence": "I have been learning English for three months.",
  "error_type": ["tense"],
  "explanation_cn": "这里强调动作从过去持续到现在，所以不能用一般过去时。",
  "better_version": "I have been studying English consistently for the past three months.",
  "similar_question_cn": "我已经练习听力两周了。"
}
```

## 4.4 错误归类系统

App 自动记录用户错误，并绑定到具体语法点。

错误类型包括：

1. 时态错误
2. 冠词错误
3. 介词错误
4. 句子结构错误
5. 从句错误
6. 非谓语错误
7. 搭配错误
8. 中式英语
9. 表达不自然

示例：

```text
错误句：
I learned English for three months.

正确句：
I have been learning English for three months.

错误类型：
时态错误

关联语法点：
现在完成时 / 现在完成进行时
```

## 4.5 相似题复练系统

用户在哪类题上出错，系统就继续生成同类题。

例如用户错了现在完成时：

```text
原题：
我已经学习英语三个月了。

复练题：
1. 我已经练习口语两个月了。
2. 他已经住在这里三年了。
3. 我已经使用这个方法十天了。
4. 她已经准备雅思半年了。
5. 他们已经合作很久了。
```

相似题复练是本项目的关键功能。真正有效的语法训练不是只看解释，而是在相似场景中反复做对。

## 五、App 页面结构

## 5.1 首页

首页展示当前能力状态，不展示固定天数。

页面内容包括：

```text
当前能力等级：基础输出阶段

推荐训练：
- 现在完成时
- 定语从句
- 介词搭配

薄弱点：
- 时态准确性
- 从句连接
- 介词使用

今日建议：
完成任意一组训练即可。
```

首页目标是让用户明确知道“现在最该练什么”。

## 5.2 能力树页面

能力树页面展示所有语法模块的状态。

示例：

```text
句子骨架：已掌握 80%
时态系统：训练中 55%
从句系统：训练中 42%
非谓语：未解锁
雅思写作句型：未解锁
```

用户点击某个语法点后，可以查看：

1. 掌握度
2. 训练次数
3. 历史错误
4. 最近表现
5. 解锁条件
6. 推荐复练题

## 5.3 训练页面

训练页面规划三种模式：

1. 中译英
2. 改错
3. 自由造句

MVP 阶段建议只做“中译英”，后续再加入改错和自由造句。

## 5.4 错题本页面

错题本支持两种分类方式。

按语法点分类：

1. 现在完成时
2. 定语从句
3. 非谓语 doing

按错误类型分类：

1. 时态错误
2. 介词错误
3. 句子结构错误
4. 表达不自然

用户可以点击某一类，直接进入专项复练。

## 5.5 学习报告页面

学习报告不按周报或月报，而是按阶段生成。

触发条件可以是：

1. 完成 50 句训练
2. 完成 100 句训练
3. 某个阶段掌握度达到标准
4. 多个语法点完成解锁

示例报告：

```text
阶段学习报告

你已完成 86 句训练。
整体正确率：74%。

进步明显的地方：
1. 主谓宾结构更稳定。
2. 现在完成时使用正确率提升。
3. 能开始使用简单定语从句。

当前薄弱点：
1. 介词搭配仍不稳定。
2. 从句连接词容易混淆。
3. 非谓语结构还需要加强。

下一步建议：
优先复练介词搭配和定语从句。
```

## 八、掌握度算法

MVP 阶段使用简单可解释算法：

```text
掌握度 = 总正确率 × 70% + 最近 5 题正确率 × 30%
```

示例：

```text
总正确率：75%
最近 5 题正确率：80%

掌握度 = 75 × 0.7 + 80 × 0.3 = 76.5
```

状态判断：

```text
0-39：薄弱
40-59：训练中
60-79：基本掌握
80-89：较熟练
90-100：熟练掌握
```

后续可以进一步加入：

1. 最近错误权重
2. 同类错误重复率
3. 自由造句表现
4. 复习间隔
5. 语法点重要程度

## 九、DeepSeek Prompt 设计

## 9.1 句子批改 Prompt

```text
你是一个英语语法训练教练，服务对象是中国英语学习者。

你的任务：
1. 判断学生英文是否准确表达中文意思。
2. 找出语法错误。
3. 给出正确句子。
4. 给出中文解释。
5. 生成一道相似训练题。
6. 只返回 JSON，不要输出多余文字。

语法点：{{skill_name}}
中文句子：{{chinese_sentence}}
学生英文：{{user_answer}}

返回格式：
{
  "is_correct": true/false,
  "score": 0-100,
  "corrected_sentence": "",
  "error_type": [],
  "explanation_cn": "",
  "better_version": "",
  "similar_question_cn": ""
}
```

## 9.2 相似题生成 Prompt

```text
你是英语语法训练题生成器。

请根据以下错误类型生成 5 个中译英训练句。

要求：
1. 中文自然。
2. 难度相近。
3. 专门训练同一个语法点。
4. 不要给英文答案。
5. 只返回 JSON。

语法点：{{skill_name}}
错误类型：{{error_type}}
原中文句子：{{original_sentence_cn}}

返回格式：
{
  "questions": [
    "",
    "",
    "",
    "",
    ""
  ]
}
```

## 9.3 阶段报告 Prompt

```text
你是英语学习诊断教练。

要求：

2. 指出薄弱点。
3. 给出下一步训练建议。
4. 不要夸大。
5. 语气具体、直接、鼓励。

```

## 十、MVP 范围

第一版只做最小训练闭环：

1. 用户登录
2. 语法能力树
3. 中译英训练
4. DeepSeek 批改
5. 错题本
6. 掌握度计算
7. 推荐下一个训练点

第一版暂不做：

1. 社区
2. 排行榜
3. 语音识别
4. 复杂会员系统
5. 大量动画
6. 复杂数据分析
7. 多端同步增强功能

MVP 目标只有一个：

```text
让用户完成一次完整的 AI 语法训练闭环。
```

## 十一、技术实现建议

### 11.1 iOS 客户端

建议技术栈：

1. Swift
2. SwiftUI
3. Combine 或 Swift Concurrency
4. 本地缓存可使用 SwiftData 或 SQLite

核心页面：

1. HomeView：首页推荐训练
2. SkillTreeView：语法能力树
3. PracticeView：中译英训练
4. MistakeBookView：错题本
5. ReportView：阶段报告

### 11.2 后端服务

MVP 可以使用轻量后端：

1. Supabase
2. Firebase
3. Node.js + PostgreSQL
4. Python FastAPI + PostgreSQL

如果是毕业设计或作品集项目，推荐：

```text
iOS App + FastAPI + PostgreSQL + DeepSeek API
```

这样结构清晰，便于展示完整工程能力。

### 11.3 AI 服务

DeepSeek API 负责：

1. 句子批改
2. 错误类型识别
3. 中文解释生成
4. 相似题生成
5. 阶段报告生成

后端需要做：

1. Prompt 管理
2. API 调用封装
3. JSON 解析与校验
4. 错误重试
5. 成本控制

## 十三、项目亮点

GrammarForge 的项目亮点包括：

1. 使用 DeepSeek API 实现句子级语法批改
2. 采用能力树而非固定周期课程
3. 根据用户错误自动生成相似训练题
4. 使用掌握度算法判断语法点是否解锁
5. 建立错误类型统计和复习队列
6. 将语法学习从规则记忆转化为输出训练
7. 适合长期迭代，也适合作为简历项目或毕业设计展示

## 十四、一句话定位

GrammarForge 是一个基于 DeepSeek API 的英语语法输出训练 App，通过能力树、AI 批改、错误归类、相似题复练和掌握度算法，帮助中国学习者把语法知识转化为真实写作和口语输出能力。
